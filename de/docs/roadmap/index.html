Roadmap

Der Status folgt dem main-Branch des GitHub-Repositorys und wird mit diesem Branch aktualisiert. Diese Seite verspricht weder ein Veröffentlichungsdatum noch eine Versionsnummer.

StatusPunkt
UmgesetztOpen-Source-Repository angelegt, unter der Apache-2.0-Lizenz
UmgesetztProduktposition und Architekturrichtung: Schicht G3.5, ein DPU-basiertes GDS-KVCache, und die Trennung zwischen der heißen Schicht und RustFS auf G4
In EntwicklungV1-Kern: Rust-KV-Engine
In EntwicklungRDMA- / RoCEv2-Kommunikationsschicht
In EntwicklungSPDK-Integration, direkter NVMe-Zugriff
In EntwicklungNVIDIA-DOCA-Integration und Arm-Cross-Kompilierung, BlueField-3-Unterstützung
In EntwicklungDatenpfad: über den Host-Speicher, danach GDS-Direktweg
In EntwicklungAnbindung an Inferenz-Frameworks (vLLM, TensorRT-LLM)

Wie die zwei Zustände zu lesen sind

Umgesetzt heißt: Das Repository existiert und die Richtung ist aufgeschrieben. Es heißt nicht, dass ein Cache läuft.

In Entwicklung heißt: Die Arbeit liegt nicht auf main. Der V1-Kern, die Rust-KV-Engine, liegt in einem separaten Pull Request. Eine Zeile auf dieser Seite wird erst umgesetzt, wenn diese Arbeit auf main liegt.

Stand 2026-10-15 enthält der main-Branch nur README.md und LICENSE. Nicht abgehakte Punkte in der README gelten hier nicht als Fähigkeiten, die das Projekt schon hat.
