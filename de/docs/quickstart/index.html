Schnellstart

In Entwicklung

Es gibt kein installierbares Release. Diese Seite ist keine Deploy-Anleitung.

Der V1-Kern von GPUCache wird in einem separaten Pull Request entwickelt und liegt nicht auf dem main-Branch. Installations- und Deploy-Schritte stehen hier, wenn V1 erscheint.

  1. Das Repository auf GitHub mit Star oder Watch beobachten, damit eine Veröffentlichung in den Benachrichtigungen erscheint.
  2. Die Architekturbeschreibung in der README lesen.
  3. In den Issues das eigene Szenario beschreiben: Inferenz-Framework, Kontextlänge, Clustergröße.
git clone https://github.com/rustfs/GPUCache.git

Der main-Branch enthält noch keinen Anwendungscode, deshalb stehen hier keine Build- oder Run-Befehle.

Was es noch nicht gibt

  • Kein installierbares Paket.
  • Keine Build-Anleitung.
  • Keine Run-Anleitung.
  • Keine Deploy-Anleitung.
