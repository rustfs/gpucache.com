Schnellstart In Entwicklung

Schnellstart

In Entwicklung

Es gibt kein installierbares Release. Diese Seite ist keine Deploy-Anleitung.

Es gibt kein installierbares Paket. Die Befehle unten führen den CPU- und TCP-Vertrag aus einem Checkout aus. Sie rollen keinen DPU aus. Die ganzen Notizen stehen in der Nutzung.

  1. github.com/rustfs/GPUCache klonen. Rust stable, MSRV 1.85, wählt rust-toolchain.toml.
  2. cargo test --workspace --all-targets ausführen. Das ist die CPU-Vertragsrepro. Die Bytes sind synthetisch.
  3. Loopback-TCP, Demos, Quoten und saubere Fehltreffer stehen in der Nutzung.
git clone https://github.com/rustfs/GPUCache.git
cd GPUCache
cargo test --workspace --all-targets

Diese Seite ist kein Produktions-Deploy. Hardwarepfade drucken NOT_RUN_HARDWARE. Siehe die Nutzung.

Was diese Seite nicht behauptet

  • Kein installierbares Paket und kein Produktions-Deploy.
  • BlueField-3, GDS, der DPU-Hardwarepfad und echte RDMA- oder NIXL-Leistung sind in Entwicklung.
  • Soft-RoCE ist nur ein funktionaler Smoke-Test, keine Leistungszahl.
  • Kein Erasure Coding und kein Haltbarkeitsreplikat auf der heißen Schicht. Ein Verlust ist ein sauberer Fehltreffer.
