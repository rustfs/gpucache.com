Quick start In development

Quick start

In development

There is no installable release. Do not treat this page as a deployment guide.

The V1 core of GPUCache is in development in a separate pull request and is not on the main branch. Install and deploy steps will be written here when V1 is released.

  1. Star or Watch the repository on GitHub so a release shows up in your notifications.
  2. Read the architecture notes in the README.
  3. Open an issue with your scenario: inference framework, context length, and cluster size.
git clone https://github.com/rustfs/GPUCache.git

The main branch does not contain application code yet, so this page does not include build or run commands.

What is not here yet

  • No installable package.
  • No build instructions.
  • No run instructions.
  • No deployment guide.
