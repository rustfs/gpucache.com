Quick start In development

Quick start

In development

There is no installable release. Do not treat this page as a deployment guide.

There is no installable package. The commands below run the CPU and TCP contract from a checkout. They do not deploy a DPU. The full notes are in the usage manual.

  1. Clone github.com/rustfs/GPUCache. Rust stable, MSRV 1.85, is selected by rust-toolchain.toml.
  2. Run cargo test --workspace --all-targets. That is the CPU contract repro. The bytes are synthetic.
  3. Read the usage manual for the loopback TCP service, demos, quotas, and clean-miss behavior.
git clone https://github.com/rustfs/GPUCache.git
cd GPUCache
cargo test --workspace --all-targets

This page is not a production deploy. Hardware paths print NOT_RUN_HARDWARE. See the usage manual.

What this page does not claim

  • No installable package and no production deploy.
  • BlueField-3, GDS, the DPU hardware path, and real RDMA or NIXL performance are in development.
  • Soft-RoCE is a functional smoke only, not a performance number.
  • No erasure coding and no hot-tier durability replica. A loss is a clean miss.
