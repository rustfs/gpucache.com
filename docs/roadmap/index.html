Roadmap

Status follows the main branch of the GitHub repository and is updated as that branch changes. This page does not promise a release date or a version number.

StatusItem
ImplementedOpen-source repository created, under the Apache 2.0 license
ImplementedProduct position and architecture direction: the G3.5 tier, a DPU-based GDS KVCache, and a split between the hot tier and RustFS at G4
In developmentV1 core: Rust KV engine
In developmentRDMA / RoCEv2 communication layer
In developmentSPDK integration, direct NVMe access
In developmentNVIDIA DOCA integration and Arm cross-compilation, BlueField-3 support
In developmentData path: through host memory, then GDS direct
In developmentInference framework integration (vLLM, TensorRT-LLM)

How to read the two states

Implemented means the repository exists and the direction is written down. It does not mean a cache is running.

In development means the work is not on main. The V1 core, the Rust KV engine, is in a separate pull request. A row on this page changes to implemented only after that work is on main.

As of 2026-10-15 the main branch contains README.md and LICENSE only. Unchecked items in the README are not treated here as capabilities the project already has.
