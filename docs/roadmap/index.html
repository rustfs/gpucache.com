Roadmap

Status follows the main branch of the GitHub repository and is updated as that branch changes. This page does not promise a release date or a version number.

StatusItem
ImplementedOpen-source repository created, under the Apache 2.0 license
ImplementedProduct position: GPUCache is the G3.5 shared KV hot tier and RustFS is the G4 cold tier. The DPU and GDS path is a direction, not a path this tree has run.
ImplementedV1 A/B/C CPU contract: identity, protocol, MemoryStore, TCP service, file backend, and quotas. This row is not the hardware path.
ImplementedV2 CPU slice: TCP transport, simulated registration, a shard-local directory, and a mock G4 cold path. One process is one shard.
In developmentV3: DPU feature gate and production-hardening stubs. Devices are not linked.
In developmentRDMA / RoCEv2 communication layer
In developmentSPDK integration, direct NVMe access
In developmentNVIDIA DOCA integration and Arm cross-compilation, BlueField-3 support
In developmentData path: through host memory, then GDS direct
In developmentInference framework integration (vLLM, TensorRT-LLM)

How to read the two states

Implemented means the CPU and TCP contract is in the main tree and can be run from source. It does not mean BlueField-3, GDS, DOCA, SPDK, or live RDMA ran.

In development means the hardware path is not a measured capability. Real RDMA and NIXL performance stay NOT_RUN_HARDWARE. Soft-RoCE is a functional smoke only, not a performance number.

A G3.5 miss or node loss is a clean miss: recompute, then write back. There is no erasure coding and no hot-tier durability replica. Cold durability is RustFS at G4. Detail is in the introduction.
