Usage

Usage

These steps run the CPU and TCP contract from a clean checkout. They do not install a package, format a disk, or open a DPU. BlueField-3, GDS, the DPU hardware path, and real RDMA or NIXL performance stay in development.

In development

There is no production deploy and no crates.io publish. Soft-RoCE is a functional smoke only, not a performance number. A G3.5 miss or a lost node is a clean miss: recompute, then write back. No erasure coding and no hot-tier durability replica. RustFS is the G4 cold tier.

Install

Rust stable is selected by rust-toolchain.toml. The declared MSRV is 1.85. There is no installable package. Clone the repository and run the CPU contract tests:

git clone https://github.com/rustfs/GPUCache.git
cd GPUCache
cargo test --workspace --all-targets

cargo test --workspace --all-targets is the one-command CPU repro for V1 A, V1 B, and V1 C, and it also covers the V2 and V3 CPU tests that are in the tree. The bytes are synthetic. They are not a vLLM KV tensor, and the command is not a bandwidth result. CI also runs cargo fmt --all -- --check and cargo clippy --workspace --all-targets -- -D warnings.

Start

The TCP service listens on loopback unless you opt in. The default bind is 127.0.0.1:9735. A non-loopback address requires --allow-remote. That flag does not turn authentication off. The process still requires a tenant credential fingerprint: 32 bytes, hex-encoded, not all zeros. Pass the hash, not a live secret. There is no unauthenticated data path.

cargo run -p gpucache-transport --bin gpucache-tcp -- serve --data-dir /tmp/gpucache-dev --tenant tenant-a --trust td-local --fingerprint <64 hex chars of a credential hash>

--data-dir is a directory of ordinary files (MANIFEST, LRU, and blocks/*.gblk). Do not point it at a device node. The process does not format NVMe, change a NIC, or touch a DPU. There is no on-disk config file. Flags are the schema. This example is a development loopback only.

Config

There is no config file. The binary flags and ResourceLimits::dev_defaults() are the schema.

FieldDefaultMeaning
bind127.0.0.1:9735Socket. Non-loopback needs allow_remote. Tests use port 0.
data_dirRequiredDirectory of ordinary files. Not a device node.
tenant, trust, fingerprintRequiredOne V1 policy. Fingerprint is 32 bytes, not all zero.
allow_remotefalseDoes not disable auth.
max_connections16Extra connections are dropped.
max_frame_bytes1 MiB in the library, 2 MiB in the binaryBody cap. Larger declared lengths are rejected before read.
pool_buffers16Read-buffer pool. Checkout fails at the cap.
io_timeout5 sRead and write timeout on each connection.

Leave GPUCACHE_RUSTFS_ENDPOINT, GPUCACHE_RUSTFS_BUCKET, GPUCACHE_RUSTFS_PREFIX, GPUCACHE_RUSTFS_ACCESS_KEY, and GPUCACHE_RUSTFS_SECRET_KEY unset unless an operator has authorized a test bucket. Unset means NOT_RUN_HARDWARE. Do not invent credentials. https:// is NOT_RUN_HARDWARE in this milestone because no TLS stack is linked.

Quotas

ResourceLimits bounds object size, in-flight requests, registrations (including committed and quarantined buffers), per-tenant in-flight bytes, global retained bytes, and per-tenant retained bytes. The idempotency table is capped and entries expire.

MemoryStore refuses admission instead of evicting. FileStore evicts the oldest unpinned committed block when a retained-byte quota would fail. It does not evict another tenant to satisfy a tenant quota, and it does not evict a pinned or quarantined block. Invalidate is the explicit client path.

Shard credits, the simulated slab cap, cold retention, and the backfill byte budget are admission ceilings for recomputable KV. They are not a measured cluster size. Do not size the hot tier as the only copy of user data.

Failure and miss semantics

GPUCache is the G3.5 shared hot tier. RustFS is the G4 cold tier. On a G3.5 miss or node loss the result is a clean miss, then recompute, then write back. There is no erasure coding and no hot-tier durability replica.

  • A hit is only a COMMITTED block with a compatible identity and a checksum that still matches.
  • ABSENT, RESERVED, WRITING, EVICTING, and QUARANTINED return no payload.
  • Miss, timeout, checksum failure, version mismatch, store outage, over-budget refill, fenced epoch, corrupt or truncated file, and transport error are recomputes. None of them is a successful hit.
  • A wrong tenant, model, tokenizer, adapter, or layout is not a hit. A wrong hit is a failure.
  • A shorter valid_length on the same hash chain is an incompatible miss. The service does not slice inside a block.
  • Lease expiry does not prove that a copy has stopped. A quarantined region stays until drain attestation or a newer fenced epoch.
  • Restart reloads committed files, bumps the epoch, and drops in-flight reservations.
  • The degrade decisions for DPU restart, GPU reset, NIC flap, storage loss, NVMe timeout, control-plane loss, and RustFS slow or down are clean misses. That table is not a hardware fault injection. No payload, no wrong hit, no permanent block.

The engine may write the recomputed block back through the same batch API. The hot tier does not repair the lost block by itself.

Ops notes

dpu-demo is the diagnostics sketch. It prints whether dpu-bf3 was selected, that DOCA, SPDK, and NVMe are not linked, that hot-tier erasure coding is off, and that each planned target is NOT_RUN_HARDWARE. It does not print payloads, fingerprints, or prompts. There is no device health counter because no device is open.

ControlPlane::begin_upgrade stops new fills. In-flight fills can still complete. rollback before finish returns to serving without a fence. finish_upgrade bumps a software generation and fences, so old epochs miss and the engine recomputes. rollback after finish fences again. The generation counter does not decrease. No BlueField firmware, BFB, or DOCA package is part of this rollback. The TCP wire format is unchanged apart from quota kind byte 8 (RateLimit) on error replies.

Rebalance fences the source and returns an empty destination directory. Fault-domain isolation removes members in that domain and refuses to remove the last member. None of these copy payload bytes.

Not operated from this tree: no NVMe format, no DPU mode change, no firmware, no IOMMU or BIOS change, no production network change. G4 live calls stay env-gated. Soft-RoCE, if anyone later smokes it, is a functional smoke only and is not a performance number.

Position and the tier split are in the introduction. Upstream detail: OPERATIONS.md and README.md.
