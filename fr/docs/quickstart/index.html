Démarrage

En développement

Il n'y a pas de version installable. Ne lisez pas cette page comme un guide de déploiement.

Il n'y a pas de paquet installable. Les commandes ci-dessous exécutent le contrat CPU et TCP depuis une extraction. Elles ne déploient pas un DPU. Le détail est dans le manuel d'utilisation.

  1. Cloner github.com/rustfs/GPUCache. Rust stable, MSRV 1.85, est choisi par rust-toolchain.toml.
  2. Exécuter cargo test --workspace --all-targets. C'est la repro du contrat CPU. Les octets sont synthétiques.
  3. TCP en loopback, démos, quotas et miss propre : manuel d'utilisation.
git clone https://github.com/rustfs/GPUCache.git
cd GPUCache
cargo test --workspace --all-targets

Cette page n'est pas un déploiement de production. Les chemins matériels impriment NOT_RUN_HARDWARE. Voir le manuel d'utilisation.

Ce que cette page ne prétend pas

  • Pas de paquet installable et pas de déploiement de production.
  • BlueField-3, GDS, le chemin matériel DPU et une performance RDMA ou NIXL réelle sont en développement.
  • Soft-RoCE est un smoke fonctionnel seulement, pas un chiffre de performance.
  • Pas d'erasure coding et pas de réplica de durabilité sur le tier chaud. Une perte est un miss propre.
