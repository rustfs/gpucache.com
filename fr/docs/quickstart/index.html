GPUCache / Documentation / Démarrage

Documentation

Démarrage

La branche main contient du code Rust exécutable pour le cache KV partagé G3.5 sur CPU/TCP. Commencez par les tests de contrat logiciel ; aucun GPU ni DPU n’est nécessaire.

En développement

Le code source est disponible. Il n’existe pas encore de version installable ni de qualification pour la production.

Compiler et tester depuis les sources

Prévoyez Rust stable avec Cargo, Git et Python 3. Le premier lancement nécessite le téléchargement des dépendances. Les tests utilisent des blocs KV synthétiques, pas les sorties d’un modèle d’inférence.

git clone https://github.com/rustfs/GPUCache.git
cd GPUCache
cargo test --workspace --all-targets

Exécuter les démonstrations CPU

Exécutez ces commandes sans endpoint ni identifiants GPUCACHE_RUSTFS_*. La démonstration cold utilise le mock par défaut et ne valide pas un service RustFS réel.

cargo run -p gpucache-transport --bin share-demo
cargo run -p gpucache-transport --bin shard-demo
cargo run -p gpucache-cold --bin cold-demo
cargo run -p gpucache-storage --bin engine-spike
cargo run -p gpucache-dpu --bin dpu-demo

Les marqueurs attendus sont REUSE_OK, SHARD_OK, COLD_CONTRACT_OK, FAKE_BLOCK_CONTRACT_OK et DPU_CONTRACT_OK. L’essai moteur vérifie des blocs entiers factices ; la démonstration DPU est une simulation sur l’hôte. Ces marqueurs ne prouvent pas l’exécution d’un moteur ou d’un périphérique réel.

Reproduire la régression CPU complète

Le script vérifie le formatage, les dépendances, Clippy, les tests, les fonctionnalités optionnelles et les démonstrations. Il désactive RustFS réel et enregistre summary.md, results.json, JUnit et les journaux. Utilisez un nouveau répertoire de sortie à chaque lancement ; --offline exige des dépendances déjà téléchargées.

cargo fetch --locked
python3 scripts/ci/vm_regression.py --profile cpu --offline --output artifacts/cpu-docs

Ce que ces vérifications ne qualifient pas

L’export/import vLLM réel, RDMA, GDS et BlueField-3 restent NOT_RUN_HARDWARE ; l’exécution GPU/modèle reste NOT_RUN_BUDGET. Aucun chemin zéro copie actif, résultat de performance matériel ou réplica durable du niveau chaud n’en découle.
