En développement

Il n'y a pas de version installable. Ne lisez pas cette page comme un guide de déploiement.

Le cœur V1 de GPUCache est en développement dans une pull request séparée et n'est pas sur la branche main. Les étapes d'installation et de déploiement seront écrites ici à la publication de la V1.

  1. Mettre une étoile ou suivre le dépôt sur GitHub pour être prévenu d'une publication.
  2. Lire la description d'architecture dans le README.
  3. Ouvrir une issue avec le scénario : framework d'inférence, longueur de contexte, taille du cluster.
git clone https://github.com/rustfs/GPUCache.git

La branche main ne contient pas encore de code applicatif, donc cette page ne donne ni commande de build ni commande d'exécution.
