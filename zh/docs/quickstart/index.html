快速开始 开发中

快速开始

开发中

暂时没有可安装的版本。不要把本页当成部署指南。

没有可安装的包。下面的命令从检出运行 CPU/TCP 契约。它们不部署 DPU。完整说明在 使用手册。

  1. 克隆 github.com/rustfs/GPUCache。Rust stable，MSRV 1.85，由 rust-toolchain.toml 选择。
  2. 运行 cargo test --workspace --all-targets。这是 CPU 契约复现。字节是合成的。
  3. 环回 TCP、演示、配额和干净未命中见 使用手册。
git clone https://github.com/rustfs/GPUCache.git
cd GPUCache
cargo test --workspace --all-targets

本页不是生产部署。硬件路径打印 NOT_RUN_HARDWARE。见 使用手册。

本页不声称的事

  • 没有可安装的包，也没有生产部署。
  • BlueField-3、GDS、DPU 硬件路径，以及真实的 RDMA/NIXL 性能，是「开发中」。
  • Soft-RoCE 只做功能冒烟，不是性能数字。
  • 没有纠删码，热层也没有持久副本。丢失是一次干净的未命中。
