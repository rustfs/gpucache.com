暂时没有可安装的版本。不要把本页当成部署指南。

GPUCache 的 V1 核心在另一个 pull request 中开发，不在主分支上。安装和部署步骤会随 V1 发布写在这里。

  1. 在 GitHub 上 Star 或 Watch 仓库，第一时间收到发布通知。
  2. 阅读 README 里的架构说明。
  3. 在 Issues 里提出你的场景和需求，比如推理框架、上下文长度、集群规模。
git clone https://github.com/rustfs/GPUCache.git
