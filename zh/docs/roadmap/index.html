路线图

状态以 GitHub 仓库主分支为准，随版本更新。本页不承诺发布日期，也不承诺版本号。

状态事项
已实现开源仓库建立，采用 Apache 2.0 许可
已实现产品定位与架构方向：G3.5 层、基于 DPU 的 GDS KVCache、热层与 G4 RustFS 分工
开发中V1 核心：Rust KV 引擎
开发中RDMA / RoCEv2 通信层
开发中SPDK 集成，直接访问 NVMe
开发中NVIDIA DOCA 集成与 Arm 交叉编译，BlueField-3 支持
开发中数据路径：经主机内存路径 → GDS 直通
开发中推理框架对接（vLLM、TensorRT-LLM）

两种状态怎么读

已实现指的是仓库已经建立、方向已经写下来。它不表示已经有一个在跑的缓存。

开发中表示这件事还不在主分支上。V1 核心，也就是 Rust KV 引擎，在另一个 pull request 里。对应行只有进入主分支之后，才会改成已实现。

截至 2026-10-15，主分支只有 README.md 和 LICENSE。README 里未勾选的事项，本站不写成项目已经具备的能力。
