路线图

路线图区分可获取的源码、可复现的 CPU 契约与硬件验证，不承诺发布日期或实测集群容量。

状态能力边界
CPU/TCP 已可运行身份、生命周期、MemoryStore/FileStore、TCP ACL 与读取准入使用合成数据测试；依赖可信网络边界，未实现 mTLS。
CPU/TCP 已可运行有界分片客户端、成员更新与 epoch fencing路由由运维方管理；没有分布式共识或集群规模认证。
mock 契约已可运行G4 v3 清单、有界写入队列、回填与保留策略真实 RustFS：NOT_RUN_HARDWARE；孤儿对象不自动回收。
CPU 模拟已可运行DPU 消息、故障注入与 TCP 功能对照没有设备卸载、零拷贝、吞吐或 TCO 实证。
伪造块实验已可运行EngineBlockContract 与 engine-spike真实 vLLM 导出／导入：NOT_RUN_HARDWARE；GPU／模型运行：NOT_RUN_BUDGET。
开发中真实 RDMA、GDS、BlueField-3 / DOCA 与 SPDKNOT_RUN_HARDWARE；可选特性不链接设备，并保持拒绝打开。

下一步所需证据

在获得 GPU 与模型资源授权后验证真实引擎，再以合适的成对基线测试硬件路径。取得证据前保留 TCO_UNKNOWN 与 NOT_EVALUATED。源码可用不代表已有可安装版本或生产就绪。

持续保持的边界

RustFS 不进入热路径。G3.5 数据丢失后重新计算，不计划增加热层纠删码或持久性副本。扩展依靠有界分片、fencing 与干净未命中，不能宣称已验证 10,000 张 GPU。
