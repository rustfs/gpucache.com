階層

各層の名前は、推論 KV Cache の階層で普通に使う呼び方です。GPUCache は G3.5 です。G4 の別名ではありません。

開発中

G3.5 の GPUCache は開発中です。表は、各層が占める予定の位置を書いています。

層媒体範囲KV Cache での役割製品
G1GPU HBMGPU 1 基生成中に使うホットな KV—
G2ホスト DRAMノード 1 台HBM から降ろした KV の一時置きとバッファ—
G3ノードローカルの NVMe SSDノード 1 台短期で再利用するウォームな KV。ノードをまたいで共有しない。—
G3.5DPU が管理し、イーサネットまたは RDMA で届く共有 NVMe フラッシュGPU ポッドまたはクラスタ内で共有再利用できる KV Cache のホット層。必要なとき G2 または G1 へ戻す。失われたら miss であり、再計算して書き戻す。GPUCache（開発中）
G4共有ネットワークストレージ（オブジェクトストレージ）データセンタ規模残すコールドデータ：モデル、データセット、セッション履歴、推論の成果物RustFS

同じ積層を、図にする

  1. G1HBM
  2. G2DRAM
  3. G3NVMe
  4. G3.5GPUCache
  5. G4RustFS

G3.5 が Signal のブロックです。G3 のノードローカル SSD より共有しやすく、G4 の共有ストレージより推論のホットパスに近い層です。

G3.5 と G4 の境界

GPUCache は永続性を持ちません。G3.5 のノードが落ちるかデータが失われると、推論フレームワークが見るのは miss です。これまでどおりプレフィルをやり直し、GPUCache に書き戻し、次はヒットできます。

長く残すコンテキストと成果物は G4 の RustFS に置きます。ホット層は再計算でき、容量層はデータを残す場所です。
