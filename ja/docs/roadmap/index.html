ロードマップ

状態は GitHub リポジトリの main ブランチに従い、そのブランチが変われば更新します。このページはリリース日もバージョン番号も約束しません。

状態項目
実装済みオープンソースのリポジトリを公開し、Apache 2.0 でライセンスした
実装済み製品の位置づけとアーキテクチャの方向：G3.5 層、DPU ベースの GDS KVCache、ホット層と G4 の RustFS の分担
開発中V1 コア：Rust KV エンジン
開発中RDMA / RoCEv2 通信層
開発中SPDK 統合と NVMe への直接アクセス
開発中NVIDIA DOCA 統合と Arm クロスコンパイル、BlueField-3 対応
開発中データパス：ホストメモリ経由から GDS 直通へ
開発中推論フレームワークとの接続（vLLM、TensorRT-LLM）

二つの状態の読み方

実装済みは、リポジトリが存在し、方向が書いてあることを指します。キャッシュが動いているという意味ではありません。

開発中は、その仕事が main に無いことを指します。V1 コア、つまり Rust KV エンジンは、別の pull request にあります。このページの行が実装済みに変わるのは、その仕事が main に入った後だけです。

2026-10-15 時点で、main ブランチにあるのは README.md と LICENSE だけです。README で未完了の項目を、ここでは既にある能力とは扱いません。
