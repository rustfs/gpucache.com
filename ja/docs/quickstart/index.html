インストールできるリリースはありません。このページを配置手順として読まないでください。

GPUCache の V1 コアは別の pull request で開発中であり、main ブランチにはありません。インストールと配置の手順は、V1 の公開時にここに書きます。

  1. GitHub でリポジトリを Star または Watch し、リリースの通知を受け取る。
  2. README にあるアーキテクチャの説明を読む。
  3. Issues に、推論フレームワーク、コンテキスト長、クラスタ規模などの利用場面を書く。
git clone https://github.com/rustfs/GPUCache.git
