クイックスタート 開発中

クイックスタート

開発中

インストールできるリリースはありません。このページを配置手順として読まないでください。

インストールできるパッケージはありません。下のコマンドはチェックアウトから CPU と TCP の契約を実行します。DPU は配置しません。全文は 利用マニュアル です。

  1. github.com/rustfs/GPUCache をクローンする。Rust stable、MSRV 1.85 は rust-toolchain.toml が選びます。
  2. cargo test --workspace --all-targets を実行する。これが CPU 契約の再現です。バイトは合成です。
  3. ループバック TCP、デモ、クォータ、クリーンミスは 利用マニュアル を読む。
git clone https://github.com/rustfs/GPUCache.git
cd GPUCache
cargo test --workspace --all-targets

このページは本番配置ではありません。ハードウェア経路は NOT_RUN_HARDWARE を出します。利用マニュアルを見てください。

このページが主張しないこと

  • インストールできるパッケージはなく、本番配置もない。
  • BlueField-3、GDS、DPU のハードウェア経路、実 RDMA / NIXL の性能は開発中。
  • Soft-RoCE は機能スモークだけで、性能値ではない。
  • イレイジャーコーディングはなく、ホット層の耐久レプリカもない。喪失はクリーンミス。
