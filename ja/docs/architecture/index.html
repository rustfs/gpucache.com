アーキテクチャ

GPUCache は KV データのホットパスを、NIC、DPU、SSD の間に置きます。以下は設計目標です。

開発中

BlueField-3 対応、DPU と GDS の直通パス、vLLM と TensorRT-LLM との接続は、いずれも開発中です。

main ブランチにあるもの

main には CPU と TCP の契約があります。V1 A/B/C、V2 スライス（TCP、シャードローカルなディレクトリ、モックのコールド経路）、V3 スタブ（DPU のフィーチャーゲートと硬化フック）です。実行できるのはその CPU 契約です。BlueField-3、GDS、DPU のハードウェア経路、実 RDMA / NIXL の性能は開発中で、NOT_RUN_HARDWARE です。Soft-RoCE は機能スモークだけで、性能値ではありません。

イレイジャーコーディングはなく、ホット層の耐久レプリカもありません。G3.5 のミスまたはノード喪失はクリーンミスです。再計算し、書き戻します。冷データは G4 の RustFS が保持します。このページの図はハードウェア経路の設計目標のままです。紹介と使い方を読んでください。

三つの役割

  • GPU 生成中に使う KV を持ち、戻す必要のある KV を取りにいきます。
  • DPU Rust KV エンジンを動かし、フラッシュを管理します。BlueField-3 対応は開発中です。
  • フラッシュ クラスタが再利用できる KV を置く共有 NVMe です。

データパス

下の線は設計目標であり、今日動いている経路ではありません。最初に通すのは、ホストメモリを経由する経路です。

  1. GPU メモリ / ホストメモリ
  2. RDMA / RoCEv2
  3. DPURust KV エンジン
  4. SPDK
  5. NVMe フラッシュ

開発中

三段階、すべて開発中

  1. ホストメモリ経路 KV はホスト DRAM と、DPU およびフラッシュの間を移動します。これが第一段階で通す基線です。
  2. 一時置きの経路 GPU メモリ上のデータを一度置き、それから DPU に渡します。過渡的な形であり、一時置きは観測できなければなりません。
  3. GDS 直通 GPU メモリが DPU を経てフラッシュに届き、ホスト側の一時置きはありません。これが GPUCache の目標の形です。

公開資料が「GDS 直通に対応」と書けるのは、実行時の証拠が取れてからです。直通の経路を実際に通り、フォールバックも黙った一時置きもなく、両端のバイトとチェックサムが一致すること。インターフェースや装置の種類だけでは、その証拠になりません。

コンポーネント

  1. 01

    Rust KV エンジン 開発中

    KV Cache 向けのストレージエンジン。Rust で書き、DPU の Arm コアで動かします。

  2. 02

    RDMA / RoCEv2 転送 開発中

    計算ノードと G3.5 の間は RDMA で通信します。

  3. 03

    SPDK によるフラッシュ管理 開発中

    DPU 上の SPDK で NVMe SSD に直接アクセスします。

  4. 04

    NVIDIA DOCA と Arm クロスコンパイル 開発中

    BlueField-3 上でビルドし、実行します。

  5. 05

    推論フレームワークとの接続 開発中

    vLLM や TensorRT-LLM などの KV Cache インターフェースへ接続する予定です。PagedAttention のブロック粒度で管理します。

CPU の境界

正確な言い方はこうです。ストレージ側に x86 のストレージホストは要らない。KV データのホットパスはホスト CPU が中継しない。計算ノードには、登録メモリ、リクエストの投入、完了イベントの受け取りという最小限の状態が残ります。

失われたときの意味

GPUCache は永続性を持ちません。G3.5 のノードが落ちるかデータが失われると、推論フレームワークが受け取るのは miss です。これまでどおりプレフィルをやり直し、GPUCache に書き戻し、次はヒットできます。

長く残すコンテキストと成果物は G4 の RustFS に置きます。RustFS が容量層、GPUCache がホット層です。

向かない用途

  • 永続して残すデータ。G3.5 はキャッシュです。永続データは G4 の RustFS に置きます。
  • 学習のチェックポイント保管。それは G4 の仕事です。
  • 今すぐ本番へ載せること。CPU 契約はソースから実行できます。ハードウェア経路は開発中で、このツリーは本番準備完了ではありません。
